# Cyber Escape

Browser-based Cyber Escape project using HTML, CSS, native JavaScript ES
modules, and the HTML Canvas API without frameworks or package dependencies.

The current step provides the responsive main menu, How To Play and Settings
screens, and a non-interactive Canvas placeholder. Gameplay has not been
implemented yet.

## Run locally

Serve this folder with any local static web server, then open its `index.html`
page in a browser. Serving the files over HTTP allows the browser to load the
JavaScript ES modules correctly.
